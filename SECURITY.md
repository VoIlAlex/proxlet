# Security Policy

proxlet sits in front of your services and can serve files from disk, so
security reports are taken seriously.

## Reporting a vulnerability

Please do not open a public issue. Report privately through
[GitHub security advisories](https://github.com/VoIlAlex/proxlet/security/advisories/new).

Include what you found, how to reproduce it, and the version or commit affected.
You should get a first response within a week.

## Supported versions

Until 1.0, only the latest release receives security fixes.
